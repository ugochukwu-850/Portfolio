# Managing this site

## Adding a new article

Create a file in `content/articles/` with a `.md` extension:

```
content/articles/my-article-title.md
```

With this front matter at the top:

```toml
+++
title = "My Article Title"
date = 2025-06-01
description = "One sentence summary shown in search results."
+++

Your article content in Markdown here.
```

That's it. The article will appear on `/articles/` sorted by date.

## Building & previewing locally

You need: `zola` and `node` / `npm`.

```bash
# Preview with live reload (only needs zola)
zola serve

# If you changed styles in input.css, recompile Tailwind first:
npm run css:build
zola serve
```

## Deploying

### Netlify (recommended, free)
1. Push this repo to GitHub.
2. Go to app.netlify.com → New site from Git.
3. Build command: `npm run css:build && zola build`
4. Publish directory: `public`
5. Done. Every push to main auto-deploys.

### Cloudflare Pages (also free)
1. Push to GitHub.
2. Cloudflare Dashboard → Pages → Connect to Git.
3. Build command: `npm run css:build && zola build`
4. Build output: `public`

### Custom domain
Once you have a domain, update `base_url` in `config.toml`:
```toml
base_url = "https://yourdomain.com"
```

## Changing content

- **Bio / intro:** Edit `templates/index.html` — look for the Hero section.
- **Projects:** Edit the Projects section in `templates/index.html`.
- **Experience:** Edit the Experience section in `templates/index.html`.
- **Skills:** Edit the Skills section in `templates/index.html`.
- **Social links:** Edit `config.toml` under `[extra]`.

## Changing styles

Tailwind utility classes are written directly in the HTML templates. To change something:
1. Open the template file.
2. Edit the Tailwind class (e.g. change `text-orange-600` to `text-blue-600`).
3. Run `npm run css:build` to recompile the CSS.
4. Run `zola build` to rebuild the site.

## File structure

```
config.toml           ← site settings, social links
input.css             ← Tailwind source (edit custom styles here)
tailwind.config.js    ← Tailwind config (dark mode, fonts)
content/
  _index.md           ← home page marker
  articles/
    _index.md         ← articles section config
    *.md              ← your articles (add new ones here)
templates/
  base.html           ← shared layout (nav, footer, dark mode)
  index.html          ← home page layout
  section.html        ← /articles/ list page
  page.html           ← single article page
static/
  style.css           ← compiled CSS (generated by Tailwind)
```
